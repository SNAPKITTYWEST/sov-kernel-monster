3. KEY THEOREM (PAR-011): Jordan Fixed-Point Commutativity
   For a Keller map F with polynomial Hamiltonian H and unitary U = exp(-iHt):
   - If ρ* satisfies T(ρ*) = ρ* (Jordan operator fixed point)
   - Then [U, ρ*] = 0 (ρ* commutes with U)
   - Therefore ρ* ∈ Comm(U), forcing F⁻¹ to be polynomial

   The proof is 11 lines of verified Lean code.
