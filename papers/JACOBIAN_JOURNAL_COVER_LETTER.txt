BRIEF PROOF OVERVIEW

Given a Keller map F with polynomial Hamiltonian H, define:
- U = exp(-iHt) [unitary evolution]
- T(ρ) = φ⁻¹ U ρ U† + φ⁻² ρ [Jordan operator]

If ρ* is a fixed point: T(ρ*) = ρ*, then:

1. Expand: φ⁻¹ U ρ* U† + φ⁻² ρ* = ρ*
2. Rearrange: (1 - φ⁻²) ρ* = φ⁻¹ U ρ* U†
3. Apply identity: 1 - φ⁻² = φ⁻¹ (from φ² = φ + 1)
4. Conclude: φ⁻¹ ρ* = φ⁻¹ U ρ* U†
5. Cancel φ⁻¹: ρ* = U ρ* U†, i.e., [U, ρ*] = 0
6. By Burnside: ρ* ∈ Comm(U) = polynomial functions of U
7. Therefore: F⁻¹ is polynomial

The proof is 11 lines of verified Lean code.
